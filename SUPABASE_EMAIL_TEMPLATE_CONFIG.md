
# Supabase Email Template Configuration - Quick Reference

## Password Reset Email Template

### Location
Supabase Dashboard → Authentication → Email Templates → Reset Password (Recovery)

### Template Code
Copy and paste this into your Supabase email template:

```html
<h2>Reset Your Password</h2>

<p>Hello,</p>

<p>We received a request to reset your password for your Recall account.</p>

<p>Click the button below to reset your password:</p>

<p style="text-align: center; margin: 30px 0;">
  <a href="{{ .SiteURL }}/update-password?token_hash={{ .TokenHash }}&type=recovery" 
     style="background-color: #3b82f6; color: white; padding: 12px 24px; text-decoration: none; border-radius: 8px; display: inline-block; font-weight: 600;">
    Reset Password
  </a>
</p>

<p>Or copy and paste this URL into your browser:</p>
<p style="word-break: break-all; color: #6b7280; font-size: 14px;">
  {{ .SiteURL }}/update-password?token_hash={{ .TokenHash }}&type=recovery
</p>

<p style="margin-top: 30px; padding-top: 20px; border-top: 1px solid #e5e7eb;">
  <strong>Important:</strong>
</p>
<ul>
  <li>This link will expire in 24 hours</li>
  <li>This link can only be used once</li>
  <li>If you didn't request this, you can safely ignore this email</li>
</ul>

<p style="margin-top: 30px; color: #6b7280; font-size: 14px;">
  Thanks,<br>
  The Recall Team
</p>
</html>
```

### Subject Line
```
Reset Your Password - Recall
```

### Critical Parameters
These MUST be included in the template:

1. **{{ .SiteURL }}** - Your app's base URL
   - Example: `https://recall.expo.app`
   - Configured in: Authentication → URL Configuration → Site URL

2. **{{ .TokenHash }}** - The hashed token for verification
   - Automatically generated by Supabase
   - Required for token verification

3. **type=recovery** - Indicates this is a password recovery flow
   - Must be exactly `recovery` (lowercase)
   - Used by `verifyOtp()` to validate the token type

### URL Format
The final URL in the email will look like:
```
https://recall.expo.app/update-password?token_hash=abc123def456...&type=recovery
```

## Configuration Checklist

### Step 1: Update Email Templates
- [ ] Copy password reset template above
- [ ] Paste into Supabase Dashboard → Authentication → Email Templates → Reset Password
- [ ] Update subject line
- [ ] Click Save

### Step 2: Configure Site URL
- [ ] Go to Authentication → URL Configuration
- [ ] Set Site URL to: `https://recall.expo.app`
- [ ] Click Save

### Step 3: Add Redirect URLs
- [ ] Go to Authentication → URL Configuration
- [ ] Add these URLs to Redirect URLs:
  - `https://recall.expo.app/update-password`
  - `https://recall.expo.app/email-confirmed`
  - `https://recall.expo.app/*`
- [ ] Click Save

### Step 4: Verify JWT Settings
- [ ] Go to Authentication → Settings
- [ ] Check JWT Expiry Limit is at least 3600 seconds
- [ ] Click Save if changed

### Step 5: Test
- [ ] Request a password reset from the app
- [ ] Check email is received
- [ ] Verify email contains correct link format
- [ ] Click link and verify it works
- [ ] Complete password reset flow

## Troubleshooting

### Email not received
1. Check spam/junk folder
2. Verify email address is correct
3. Check Supabase email service status
4. Review Supabase logs for email delivery errors

### Link doesn't work
1. Verify template includes `token_hash` and `type` parameters
2. Check Site URL is configured correctly
3. Verify redirect URLs are in allowlist
4. Check link hasn't expired (24 hours)
5. Ensure link hasn't been used already (single-use)

### "Invalid Link" error
1. Token may have expired (24 hours)
2. Token may have been used already (single-use)
3. Token format may be incorrect (check template)
4. Type parameter may be wrong (must be "recovery")

## Testing Template Changes

### Test Email
After updating the template, test it:

1. Go to Authentication → Users in Supabase Dashboard
2. Find a test user
3. Click the three dots menu
4. Select "Send password recovery email"
5. Check the email received
6. Verify the link format is correct

### Test Variables
Verify these variables are replaced correctly:
- `{{ .SiteURL }}` → `https://recall.expo.app`
- `{{ .TokenHash }}` → Long alphanumeric string
- `{{ .Email }}` → User's email address (if used)

## Best Practices

### Email Design
- Keep it simple and clear
- Use a clear call-to-action button
- Include plain text URL as fallback
- Add expiry information
- Include security tips
- Use your brand colors

### Security
- Always use HTTPS URLs
- Include expiry information
- Mention single-use nature
- Add "didn't request this?" message
- Don't include sensitive information

### Accessibility
- Use semantic HTML
- Ensure sufficient color contrast
- Make buttons large enough to click
- Include alt text for images
- Test with screen readers

## Support

### If you need help:
1. Check Supabase documentation: https://supabase.com/docs/guides/auth/auth-email-templates
2. Review app logs for detailed error messages
3. Check Supabase status page: https://status.supabase.com
4. Contact Supabase support if needed

### Common Questions

**Q: Can I use custom HTML/CSS?**
A: Yes, but keep it simple. Some email clients don't support advanced CSS.

**Q: Can I use images?**
A: Yes, but host them externally and use absolute URLs.

**Q: Can I customize the sender name?**
A: Yes, in Authentication → Settings → Email Auth → Sender Name

**Q: Can I use a custom domain?**
A: Yes, configure SMTP settings in Authentication → Settings

**Q: How long do tokens last?**
A: 24 hours by default, configurable in Supabase settings

**Q: Can tokens be reused?**
A: No, tokens are single-use only for security
